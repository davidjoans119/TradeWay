TRADEWOOD SNEAKER STORE — DEMO

1. Extract the ZIP.
2. Open index.html in a modern browser, or deploy the whole folder to Netlify / Vercel.
3. Keep the assets folder beside index.html.

Included:
- Responsive storefront inspired by the supplied reference
- User-supplied shoe photo
- Pointer/touch drag interaction with CSS 3D perspective tilt
- Cart drawer and demo checkout interaction

Important:
The supplied photo is a single photograph, not a 3D shoe model. The drag interaction tilts the image in perspective; it cannot reveal unseen sides of the shoe. For true 360-degree rotation, replace the image interaction with a GLB/GLTF 3D model or provide a complete set of multi-angle product photos.
Prices, product names, store branding, cart and checkout are demo content and should be customized before launch. No payment gateway, inventory, customer accounts, or order backend is connected.
